## 2. `ai-adapter status` — 現在の状態表示

### 概要

`ai-adapter` の初期化状態と登録データのサマリーを表示する。

### 実装（既存）

`src/ai_adapter/cli.py:42-71` に実装済み。表示内容は以下の通り:

- データディレクトリ (`~/.ai-adapter/`)
- 設定ファイルパス
- バージョン
- デフォルト環境名
- 登録エージェント数
- 登録環境数
- 登録スクリプト数
- エージェント紐付け数
- `agents/` ディレクトリの有無
- `bin/` ディレクトリの有無

## 3. `ai-adapter uninstall` — 初期化解除・データ削除（新規実装）

### 概要

`~/.ai-adapter/` ディレクトリを削除し、ai-adapter の初期化を解除する。  
ユーザーに確認を促した上で削除を実行する。

### 実装方針

1. 新規ファイル `src/ai_adapter/uninstall.py` にコマンドを実装
2. `cli.py` で `main.add_command(uninstall_command)` で登録
3. `~/.ai-adapter/` の存在確認 → 存在しなければエラー
4. 確認プロンプト → `click.confirm()` を使用
5. `shutil.rmtree()` で `~/.ai-adapter/` を削除
6. `.github/agents/`, `.github/bin/` などプロジェクト側のファイルは削除しない

### シグネチャ

```python
@click.command(name="uninstall")
def cmd_uninstall() -> None:
    """~/.ai-adapter/ を削除して初期化を解除する。"""
```

### 動作イメージ

```bash
$ ai-adapter uninstall
~/.ai-adapter/ を完全に削除します。
この操作は元に戻せません。続行しますか？ [y/N]: y
ai-adapter をアンインストールしました。
  - 削除: /Users/xxx/.ai-adapter/config.yaml
  - 削除: /Users/xxx/.ai-adapter/agents/
  - 削除: /Users/xxx/.ai-adapter/bin/
  - 削除: /Users/xxx/.ai-adapter/

# 未初期化の場合
$ ai-adapter uninstall
ai-adapter は初期化されていません。
```

### 実装詳細

```python
"""uninstall コマンドの実装。

~/.ai-adapter/ ディレクトリを削除して初期化を解除する。
"""

from __future__ import annotations

import logging
import shutil

import click

from ai_adapter import config as _config

logger = logging.getLogger(__name__)


@click.command(name="uninstall")
def uninstall_command() -> None:
    """~/.ai-adapter/ を削除して初期化を解除する。"""
    adapter_dir = _config.AI_ADAPTER_DIR

    if not adapter_dir.exists():
        click.echo("ai-adapter は初期化されていません。")
        return

    click.echo(f"{adapter_dir}/ を完全に削除します。")
    click.confirm("この操作は元に戻せません。続行しますか？", abort=True)

    try:
        shutil.rmtree(adapter_dir)
        click.echo("ai-adapter をアンインストールしました。")
        click.echo(f"  削除: {adapter_dir}/")
    except OSError as e:
        logger.error("アンインストール失敗: %s", e)
        raise click.ClickException(f"アンインストールに失敗しました: {e}")
```

### `cli.py` への追加

```python
from ai_adapter.uninstall import uninstall_command

# ファイル末尾に追加
main.add_command(uninstall_command)
```

## 4. テスト

### テストファイル

| テスト対象 | ファイル |
|-----------|---------|
| `uninstall` コマンド | `tests/test_uninstall.py`（新規） |

### テストケース

```python
# tests/test_uninstall.py
import tempfile
import unittest
from pathlib import Path
from click.testing import CliRunner

from ai_adapter.cli import main


class TestUninstallCommand(unittest.TestCase):
    """ai-adapter uninstall のテスト。"""

    def setUp(self):
        self.runner = CliRunner()
        # init で作られる ~/.ai-adapter/ をテンポラリで代替
        # → config.py の AI_ADAPTER_DIR を一時ディレクトリに差し替え

    def test_uninstall_success(self):
        """通常のアンインストール（確認プロンプトに y で応答）。"""
        result = self.runner.invoke(main, ["uninstall"], input="y\n")
        # ...

    def test_uninstall_cancel(self):
        """確認プロンプトで n を選んだ場合は中断。"""
        result = self.runner.invoke(main, ["uninstall"], input="n\n")
        # ...

    def test_uninstall_not_initialized(self):
        """未初期化状態でのアンインストール。"""
        result = self.runner.invoke(main, ["uninstall"])
        # ...
```

**注意**: `~/.ai-adapter/` を実際に操作するため、テスト実行時は `config.py` の `AI_ADAPTER_DIR` を `tempfile.TemporaryDirectory` に差し替えること。
