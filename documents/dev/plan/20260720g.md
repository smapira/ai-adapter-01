## (c) ~/.ai-adapter/ に移動して Git リモートを設定（ここだけ手動）
cd ~/.ai-adapter
git remote add origin git@github.com:smapira/ai-adapter-config.git

今の実装では、これがユーザー側で手動でやることになっていますが、そうではなくて、セットアップコマンドなどで、最初にユーザーに共有先を登録させるようなユースケースにしてください。 

例
ai-adapter start URL(ex, git@github.com:user/my-agent-config.git)

and

ai-adapter init
proment say : sort of, first of all, you need to input your remote reposityr url
